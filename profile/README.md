# Welcome to AerynOS

Welcome to the development home of AerynOS. AerynOS should be considered an in-development, Alpha quality, tech preview Linux distribution, which primarily exists to prove out our tooling approach at this point in time.

All of our tooling is being built from the ground up, predomentantly using Rust with an aim to solve issues prevalant with Linux Distributions at the tooling level. By starting from the ground up, we are able to combine existing approaches with new solutions in novel ways to eventually deliver a technology stack that will make developing and maintaining a Linux distrubtion a much easier endevour.

## 🛠 Tooling

Our [os-tools](https://github.com/AerynOS/os-tools):

- moss - system state and package manager
- boulder - moss-format build tool

Our [infrastructure](https://github.com/AerynOS/infra) tooling:

- summit - build controller
- vessel - repo manager
- avalanche - build worker middleware

Written in Rust and currently in active development to flesh out features and capabilities.

## 📚 Documentation

Dive into our [documentation](https://aerynos.dev) website to learn more about our philosophy, packaging guidelines and find other helpful information.

Contributors can submit PRs to documentation in the [dotdev](https://github.com/AerynOS/dotdev) repository that once approved, will reflect on our documentation website.

## 🧾 Recipes

AerynOS uses a mono-repo approach for our [recipes](https://github.com/AerynOS/recipes) repository. Our focus is squarely on maintaining our currently supported Desktop stacks + development tooling.

For the curious amongst you, you can head to our recipes repository to find out more about the packages we currently offer and for guidance on how to package for AerynOS.
